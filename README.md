#### 安装汉化补丁

> 注意：进行以下步骤之前，建议手动将游戏文件夹备份，以防不测。一旦出现任何问题，作者概不负责。

1. 首先要拥有一份干净的游戏文件，即没有装过任何自定义模组和其他汉化程序的游戏文件。

> 干净的游戏文件列表，可以参考[此文件](tutorial/filelist.txt)

2. 通过本页面上方链接下载最新软件包。

![](tutorial/001.png)

2. 将下载得到的 NieR_Chinese.zip 文件解压到任意自己能找到的位置，建议将程序文件夹放到游戏文件夹中，方便后续升级或卸载汉化补丁。

![](tutorial/002.png)

3. 打开 NieR_Chinese 文件夹，启动 LangTools.exe 。

![](tutorial/003.png)

4. 选择游戏文件所在位置，默认情况下，如果你是 Steam 正版玩家，并且已经正常安装好了游戏，程序可以自动获取到游戏文件的位置。  
如果程序没有获取到游戏位置，那么你只需要启动一次游戏，点击程序右上角的“自动定位”按钮就可以自动填写游戏路径。

![](tutorial/004.png)

5. 确保游戏路径选择正确，在下面勾选需要安装的组件，点击“安装”按钮，等待提示完成即可。

![](tutorial/005.png)

6. 关闭补丁管理程序，打开 Steam，进入库的 NieR:Automata 页面。点击右边齿轮，选择“属性。”  
在“通用”选项卡中，将语言改成“德语”。

![](tutorial/006.png)
![](tutorial/007.png)

7. 启动游戏，恭喜，你已经可以享受中文版本的 NieR:Automata 了。

#### 移除汉化补丁

> 注意：进行以下步骤之前，建议手动将游戏文件夹备份，以防不测。一旦出现任何问题，作者概不负责。

1. 打开 NieR_Chinese 文件夹，启动 LangTools.exe 。

2. 设定好游戏文件夹的路径。

3. 点击程序右下角的“移除补丁”按钮，等待提示完成即可。
